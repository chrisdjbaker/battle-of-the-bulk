# Battle of the Bulk — Tournament Hub

A single-file, offline tournament site for **The Colosseum Gaming Lounge** (Rusk, TX): contestants, randomized kit draw, single-elimination or Swiss brackets, results, and a live TV display.

- **Online:** served by GitHub Pages from `docs/index.html`.
- **USB stick:** copy the `USB/` folder and double-click `Battle of the Bulk.html` (see `USB/READ ME FIRST.txt`).

## Editing
Edit `src/index.html`, then run `python3 build.py` to rebuild `USB/Battle of the Bulk.html` and `docs/index.html` (images from `src/assets/` are embedded).
